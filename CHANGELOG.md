# Changelog

## v0.2.0 — Gen III region migration

- Migrated the desktop UI and scanner foundation to Tauri + Rust.
- Added Hoenn region support for Pokémon Emerald, Ruby, and Sapphire.
- Added Kanto region support for Pokémon FireRed and LeafGreen.
- Added party and wild Pokémon scanning with IV, nature, ability, checksum, and shiny information.
- Added first-launch region selection and a Change Region action.
- Added translucent themed panels, menu transitions, sound effects, and hunting counters.
- Bundled sprites and UI assets for offline use.
